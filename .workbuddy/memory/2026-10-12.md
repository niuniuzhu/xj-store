# 2026-10-12 工作日志

## 新增功能
用户选定两项：优惠券下单抵扣 + 卡密自助兑换页。

### 1. 优惠券下单抵扣
- `server/pay-server.js`：
  - 新增 `validateCoupon(code, afterMember, level, subtotal)` 辅助函数（amount 减额 / rate 打折；校验 存在/启用/未过期/未领完/等级匹配/门槛）。
  - 满减门槛按**原价 subtotal** 判定（不是会员折后价），会员（如 SVIP 折后很低）也能用券。
  - 新增 `POST /api/coupon/validate`（结算页预览，返回 discount）。
  - `POST /api/order` 在会员折扣之后叠加优惠券：先算会员折后 `afterMember`，再减券额 → `total`；券有效才计入并 `used+1`，无效则忽略不阻断下单；响应新增 `couponDiscount` 字段。
- `checkout.html`：新增"优惠券"区块（输入+应用按钮），调用 validate 预览，概要区显示券后金额；提交带 `coupon` 字段，服务端返回后覆盖本地订单金额。
- `login.html`：新增 `?back=` 回跳支持（登录/注册成功后跳回指定页，allowlist 限制）。

### 2. 卡密自助兑换页
- `server/pay-server.js`：
  - 新增 `POST /api/card/redeem {code, uid}`：校验卡密未用 + 批次 `reward`，给账户加等级/积分；标记 used 并记录 `acct.redemptions`；封禁/未登录拦截。
  - `publicAccount` 新增 `vipExpireAt`、`redemptions` 字段（前端可显示）。
- `server/data/cards.json`：首发批次（id 1）加 `"reward": {"type":"level","level":"svip","days":30}`，使未用卡密可兑换（升级 SVIP 30 天）。未用测试码如 `XJ-89095606D7` 等可直接试。
- `redeem.html`（新建）：登录后输入卡密兑换，展示结果与最新等级/积分，刷新本地 user 与兑换记录。未登录引导登录（`?back=redeem.html`）。
- `me.html`：资料卡菜单加"卡密兑换"入口；右侧新增"我的兑换记录"区块（拉 `/api/account/me` 权威数据并同步本地）。
- `assets/base.js`：顶栏导航新增"兑换"（gift 图标）；新增 `ICON.gift`。
